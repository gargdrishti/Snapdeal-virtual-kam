# 1-2 minute screen recording script
Use Chrome, headphones on, mic allowed. Record the whole window (call card + side panels visible). Say the seller lines aloud.

1. (0:00) Show the page. Press **"KAM calls seller (proactive)"**. Riya opens with the sales drop; note the `get_seller_metrics` tool in Agent activity.
2. (0:15) Seller: "Yes, I have a few minutes." -> Riya cites orders -32%, out-of-stock 5 -> 18, asks why. (Point at the snapshot table.)
3. (0:35) Seller: "My supplier delayed the goods." -> Riya moves on to cancellations 8% -> 14%, asks about dispatch time.
4. (0:50) Seller: "I usually dispatch in about three days." -> Riya notes slow dispatch, mentions impressions down 35%, asks about changes.
5. (1:05) Seller: "No, I haven't changed anything." -> Riya gives the rupee breakdown (see the bar) and 3 recommendations.
6. (1:25) Seller: "Yes, please set that up." -> tool calls fire; **Actions taken** fills (restock task, ticket, follow-up, WhatsApp). Riya summarises and promises a 48h call-back.
7. (1:50) Click **Skip to day 3** (or "Fast-forward 48 hours"). Riya calls back with measured progress; say "Yes, set that up" and show the "48 hours later" section and the new stamp.
8. Optional: in another call say "This is useless, I want a human" to show the handoff, or switch to Hindi.
Tip: the whole script is ~2 min; cut step 3 or 4 if you need it shorter.
Tip: also try interrupting Riya mid-sentence with "Allow interrupting" ticked.
